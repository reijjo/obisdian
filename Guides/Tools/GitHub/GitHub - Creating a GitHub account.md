# GitHub - Creating a GitHub account
1. Go to <https://github.com/>
2. Sign up
3. Check your email for verification code
4. Login

## Creating a repository
1. Click **Create repository** on your dashboard
2. Give your repository a name and short description
3. Add README + Add .gitignore (_bun_ or _Next.js_ is a safe choice)
4. Click **Create repository**

## SSH keys
Skip this if your SSH keys are ok, otherwise [[GitHub - Adding SSH keys]]
## Cloning a repository
1. Choose your project in your repositories page
2. Click on the green *<> Code* button
3. Clone with SSH
4. Copy the address
5. Run `git clone and-the-copied-address`in your terminal and that's it
