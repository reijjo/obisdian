# Deployment to Vercel
1. Push your project to your GitHub
2. Go to www.vercel.com and log in with your GitHub account
3. Click **Add New --> Project** 
4. Select the GitHub repo you want to deploy
5. Make sure the _Root Directory_ and _Application Preset_ matches on the project
6.  Click **Deploy**
That's it. Vercel gives you a public URL where your app is live.

## Environment variables
Add your _.env_ files secrets to Vercel:
- Open your project in Vercel
- Settings --> Environments --> Production --> Environment Variables --> _Add Environment Variable_
