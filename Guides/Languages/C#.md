# C\#

## Requirements
- Download *.NET SDK* <https://dotnet.microsoft.com/en-us/download>
- Install _C# Dev Kit_ extension in VS Code
## Basics
### Creating a project
1. Create folder for your project _mkdir project-name_
2. Run `dotnet new console` (without top-level statements `dotnet new console --use-program-main`)

Or just shorter way
1. `dotnet new console --use-program-main -o project_name`

Then `dotnet run` to run the project
